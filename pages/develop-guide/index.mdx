## 공통 파라미터

모든 API 요청 시 공통 파라미터를 JSON Body에 포함하여 요청해야 합니다.

| 필드명     | 타입     | 필수 | 길이 | 설명                      |
| ---------- | -------- | ---- | ---- | ------------------------- |
| `mchtTrNo` | `String` | Yes  | 50   | 가맹점거래번호            |
| `trTime`   | `String` | Yes  | 14   | 거래일시 (YYYYMMDDHHMMSS) |
| `mid`      | `String` | Yes  | 10   | 이용기관코드              |

### 요청 예시

<CodeBlock>
```json
{
  "mchtTrNo": "123456789",
  "trTime": "20260101235959",
  "mid": "C000000000",
  ...
}
```
</CodeBlock>
