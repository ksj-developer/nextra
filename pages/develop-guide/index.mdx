## 공통 파라미터

모든 API 요청 시 공통 파라미터를 JSON Body에 포함하여 요청해야 합니다.

| 필드명   | 타입   | 길이    | 필수 | 설명                      |
| -------- | ------ | ------- | ---- | ------------------------- |
| mchtTrNo | String | 60 Byte | ✅   | 가맹점거래번호            |
| trTime   | String | 60 Byte | ✅   | 거래일시 (YYYYMMDDHHMMSS) |
| mid      | String | 60 Byte | ✅   | 이용기관코드              |

### 요청 예시

```json
{
  "mchtTrNo": "123456789",
  "trTime": "20260101235959",
  "mid": "C000000000",
  ...
}
```
