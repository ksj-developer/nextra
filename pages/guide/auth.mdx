## 인증 방식

본 API 는 인증키 기반으로 호출됩니다.<br />
운영서버 인증키는 KICC 로 요청하여 받은 후 **Header** 값에 넣고 호출 하시길 바랍니다.<br />
**개발서버 인증키** : `Hxs8PkwSPn+Fo2m78aPvrw==`

## 요청 Header

| Key          | Value            | 필수 |
| ------------ | ---------------- | ---- |
| Content-Type | application/json | Yes  |
| authKey      | YOUR_AUTH_KEY    | Yes  |

<Callout type="warning">개발된 Application이 **운영으로 이관되면 반드시 운영 API 인증키로 변경**해 주어야 정상거래가 가능합니다.</Callout>
