## 은행 코드

요청 Parameter 중 `bankCd`(은행코드) 값은 아래 은행코드를 참고하여 요청하시길 바랍니다.

| 은행코드 | 은행명           |
| -------- | ---------------- |
| 002      | 산업은행         |
| 003      | 기업은행         |
| 004      | 국민은행         |
| 007      | 수협             |
| 011      | 농협은행         |
| 020      | 우리은행         |
| 023      | 제일은행         |
| 031      | 대구은행(iM뱅크) |
| 032      | 부산은행         |
| 034      | 광주은행         |
| 035      | 제주은행         |
| 037      | 전북은행         |
| 039      | 경남은행         |
| 045      | 새마을금고       |
| 048      | 신협             |
| 071      | 우체국           |
| 081      | 하나은행         |
| 088      | 신한은행         |
| 089      | 케이뱅크         |
| 090      | 카카오뱅크       |

<Callout type="warning">
  **개발서버**에서는 요청 Parameter 중 `acctNo` (계좌번호) 값은 반드시 **테스트계좌**로 요청해주시길 바랍니다. **테스트계좌**는 KICC로
  문의해주시길 바랍니다.
</Callout>
