### API 소개

KICC 펌뱅킹 연동을 위한 RESTful 기반의 API 서비스입니다.<br />
JSON 방식의 직관적인 API를 통해 펌뱅킹 기능을 연동할 수 있습니다.

### API 도메인

| 구분 | URL                                |
| ---- | ---------------------------------- |
| 개발 | https://devcmsapi.kicc.co.kr/firm/ |
| 운영 | https://cmsapi.kicc.co.kr/firm/    |

### 요청 방식

| 구분        | 설명             |
| ----------- | ---------------- |
| 프로토콜    | HTTPS            |
| 데이터 형식 | application/json |
| 네트워크    | 인터넷망         |

### API 처리 흐름

**1. API 요청 생성**  
 Application에서 INPUT 데이터를 구성하여 API를 호출합니다.

**2. 요청 및 응답 처리**  
 INPUT 데이터가 API 서버로 전달되며, 서버에서는 요청을 처리한 후 응답 데이터를 OUTPUT 형태로 반환합니다.

**3. 은행 처리**  
 API 서버는 해당 전문을 은행으로 전달하여 요청을 처리하고, 그 결과를 수신합니다.

**4. 결과 활용**  
 Application에서는 반환된 OUTPUT 데이터를 추출하여 비즈니스 로직에 활용합니다.

<Callout type="info">위 프로세스는 출금이체를 포함한 펌뱅킹 API 호출 전반에 공통적으로 적용됩니다.</Callout>
