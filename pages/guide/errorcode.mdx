## 오류 코드

API 호출 후 반환되는 `resCd` (응답 코드)와 `resMsg` (응답 메시지)를 통해 거래의 성공 여부와 실패 사유를 확인할 수 있습니다.

| 코드 | 메시지                                                                 |
| ---- | ---------------------------------------------------------------------- |
| 0000 | 정상                                                                   |
| NOTD | 정의되지 않은 오류 코드입니다.                                         |
| R001 | 인증키값이 유효하지 않습니다.                                          |
| R002 | 활동중인 이용기관이 아닙니다. KICC로 문의바랍니다.                     |
| R003 | 비정상 접속                                                            |
| R004 | 사용자 취소                                                            |
| R005 | 예상치 못한 오류입니다. KICC로 문의바랍니다.                           |
| R006 | 지원하지 않는 모듈 형식 오류                                           |
| R007 | 암복호화 오류가 발생하였습니다.                                        |
| R008 | 업무 마감시간 입니다. (23:50 ~ 00:10)                                  |
| R009 | 이미 등록된 계좌입니다. (중복등록 불가)                                |
| R010 | 파일 생성에 실패하였습니다. KICC로 문의바랍니다.                       |
| R011 | 사용 불가능한 API KEY 입니다. KICC로 문의바랍니다.                     |
| R012 | 암호화 키를 발급 받으셔야 이용 가능합니다.                             |
| R013 | {0}값을 암호화 하여 주시길 바랍니다.                                   |
| R014 | 등록전문 전송구분이 API가 아닙니다. KICC로 문의바랍니다.               |
| R015 | 등록되지않은 은행입니다. KICC로 문의바랍니다.                          |
| R016 | 등록되지않은 MID입니다. KICC로 문의바랍니다.                           |
| R017 | 등록되지않은 이용기관입니다. KICC로 문의바랍니다.                      |

| R019 | 값이 없습니다.                                                         |
| R101 | 전문 통신 예외 발생. KICC로 문의바랍니다.                              |
| R102 | 값이 비었습니다.                                                       |
| R103 | 값이 최대길이를 초과했습니다.                                          |
| R104 | DB Update 에러 입니다.                                                 |
| R105 | 전문 응답 에러 발생. KICC로 문의바랍니다.                              |
| R106 | {0}값의 길이가 유효하지 않습니다.                                      |
| R107 | 중복된 요청입니다.                                                     |
| R108 | {0}값이 유효하지 않습니다.                                             |
| R109 | 환불할 내역이 없습니다.                                                |

| R115 | 이미 해지된 출금계좌입니다.                                            |

| R299 | 예상치 못한 오류입니다. KICC로 문의바랍니다                            |
| R400 | 잘못된 요청입니다.(서버 오류)                                          |

<Callout type="warning">
  `resCd`가 `0000`이 아닌 모든 경우는 실패입니다. <br />
  실패 시에는 `resMsg`에 담긴 사유를 확인하여 고객에게 안내하거나 시스템적으로 처리해야 합니다.
</Callout>
